reopening verifies both heroes, all 69 bat models, both rope renderers and Silence
input recapture. Four original-camera CPU frames show animated bats. The saved
scene is sampled on 24/30/60 FPS grids; that is not three fresh combined exports.
Separate feature checks cover their own cameras, rollback and fractional inputs.

The actual combined report retains 1,084 unsupported/unavailable occurrences:

range and three derived component notes. These are not counts of visibly missing
effects. The output-born groups are trooper deaths (6), spirit XP (4), Crossbow

Silence schema 3. Mixed observation envelopes are rejected, and that refusal is
not subtracted from the combined report. The derived notes retain Mina's mask
stop/availability transition and two parent mask ambient/sugar-rush omissions.

Original RNG, native shared render clocks, lifetime joins/endcaps, wider
shaders/sheets, Linux/new-build profiles and exact Source/map lighting remain
unqualified. Explicit partial-export consent is still required. Missing capture
is unavailable, never proof of an empty scene. No baked test scene or detached
