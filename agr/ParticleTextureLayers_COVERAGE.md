Texture composition, constructor-default admission, renderer snapshots and rope
input resolution are synchronous transformations over one supplied input set.
The C# snapshot reader only reads the effective dictionaries; it never calls the
getter that creates missing control points. Its actual helper oracle checks
inheritance, local override isolation and unchanged missing-input counters.
Python context validation keeps external/authored/missing input provenance strict.

The deterministic rope seed transformation is an explicit approximation of the
unavailable engine seed; it adds no PRNG owner or state across calls. The default
adapter hashes a selected particle module once and returns a copied immutable
description; it adds no cache, retry, queue, thread, lock or persistent lifecycle.
These calculations therefore need no additional state model. Blender graph and
image allocation stays in the existing whole-instance package transaction,
modeled by ParticleModelAdmission.tla and checked with actual late-failure rollback.
Rope sample visibility and camera-dependent geometry keep the existing policy.

Released static/multiplied sprite profiles and explicit replacement distortion
use the original material path. Additional composition uses the shared bounded
layer interpreter. The default zoom/distortion amounts require measured module
provenance; an unknown module or explicit null is not a qualified default.
Unknown/missing per-particle inputs, unsupported rope offsets and animated atlas
sources continue to fail. Numeric, native instruction, rendered-pixel, reopened
material and full normal-export checks are distinct evidence scopes. None proves
native GPU filtering, original randomness, Source lighting or fresh replay capture.

Renderer alpha scaling also consumes this same immutable per-system context via
render_scalar. Literal behavior remains on the same scalar math; dynamic CP/age
inputs require actual snapshots and the existing input-provenance checks. This
adds no new state owner or lifecycle. Keyed alpha uses the existing scene bake;
missing/invalid snapshots still trigger the whole package's allocation rollback.

Collection-age curve UV inputs require the same actual per-system snapshots;
shot elapsed time cannot substitute for a child's collection age. Raw UV origin
is keyed, then wrapped in the shader after time interpolation. For clamped UVs,
each source corner is transformed and clamped before triangle interpolation.
This pure graph/math change removes keyed wrapped/clamped endpoint ambiguity,
adds no lifecycle, and remains inside the package allocation transaction.
The alpha/UV pixel fixture checks both paths, fractional frames, save/reopen and
late missing-child rollback. Its analytic byte-ramp texture distinguishes the
old wrapped-endpoint graph at frame2.25 (32/255) from the corrected96/255.
