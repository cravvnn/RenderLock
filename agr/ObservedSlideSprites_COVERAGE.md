# Captured slide sprites

`observed_slide_sprite_geometry` is a stateless per-call adapter. It holds no
particle/root identity, process handle, clock progression, cache, playback
handler or allocation transaction across calls. It resolves measured renderer
values into a copy, checks original accepted texture indices, and calls the same
camera-bound math extracted from the observed ambient study. Signed roll/yaw/
pitch texture scale follows the installed shader selectors7/8/9; zero scale
remains refused. The ambient backend has a separate supplied-input admission
entry point and independent normal/save/render qualification.

The optional `observed_slide_sprite_effects` stage validates a complete reference
and uses the existing `simulated_effect_package` transaction. Its source profile,
replay/scene identity, native clock mapping, exact endpoints, read budgets, raw
SIMD arrays and renderer/context bounds are checked before allocation. Collection
absence, known-empty arrays and missing data have separate representations.
`ObservedSlideSpriteFrames` models complete immutable input admission and ordered
whole-frame publication with two ticks and two dynamic root slots. Its1267states/
depth5 and four killed identity/missing/reuse/prefix mutants cover those guards.
Named returned states permit deadlock checking; no real-process or unbounded
liveness is claimed. Numeric/native/renderer semantics need independent checks.

The retained upstream `ObservedSpriteFrames` study and `ModifierMaskRender` cover the old ambient
projection and generic allocation/rollback. The new builder adds no independent
transaction, simulator lifetime or tracking protocol. Material/image dictionaries
are local to one build and keyed by immutable pinned resource/renderer inputs;
changing measured UV scales are baked into each frame mesh, never cached as
material uniforms. The scene frame restores in `finally`; actual postallocation
failure/rollback and saved/reopened checks exercise the surrounding Blender calls.
This is a finite component model composed through the existing transaction
interface, not a whole-program proof. Simplification keeps complete frame arrays
and removes any need for cross-frame IDs, inferred births or reuse of old roots;
no state-count reduction claim. Fixed/FIT animation is admitted only on static sheets;
no age/birth/seed is invented to feed a manual-only renderer. Multi-frame manual
atlases consume the native gathered input. Other timing remains refused.

`research/ParticleProbe/ParticleSheetImages` is also one-call/stateless. Exact
duplicate image records1..4 can be represented by one rectangle independent of
selection. It adds no sheet cache/publish/output lifetime. The existing converter
staging/identity/publication owns output state, unchanged and not newly proved.
Distinct cropped/uncropped rectangles, nonfinite vectors, channel splitting and
alpha cropping remain unavailable. Actual before/after texture extraction and
an actual method oracle exercise this boundary; no model substitutes for those
byte/UV checks. No whole-program or state-count reduction claim is made.
