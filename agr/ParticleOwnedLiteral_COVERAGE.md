# Pending owned literal-at-birth provider

`particle_owned_literal` validates the exact complete owned flashbang profile:
CREATE2, CP0 position, CP1 position, RELEASE, consecutive at one birth tick.
It checks generation/serial identity, original resource hash, event fields,
finite explicit positions, absent orientation and zero interpolation. Earlier
births, world effects, entity binding changes and unknown lifecycles refuse.
The native handler's absent-orientation default is initialized from its actual
registered current-build initializer; no identity value was injected as proof.

The normal path checks current installed client/particle module hashes and all
13 definition hashes before simulation. Its package binds replay/range/full
source/events/native profile and rechecks the helper's literal/materialized-CP
acknowledgments. Other model/world providers cannot be mixed into this profile.
The original event/request data is passed unchanged to the existing helper.
RELEASE is ownership release, not particle death. Seeds and spawn age retain
the existing explicit AGR approximations.

These are pure validators/snapshot projections, not a new lifecycle or clock.

with the existing conversion cache and Blender transaction. The same 40-state,
5-mutant model still applies. `ParticleProjectedScene.tla` separately keeps
initial/final whole-scene world/unknown/instance/pending-map checks strict. Its
known-profile interface now includes the exact flashbang ground layer, whose
receiver overrides are absent and retain qualified world/water-only defaults.
