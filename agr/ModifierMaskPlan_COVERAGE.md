# Sustained cosmetic mask input planner

`ModifierMaskPlan.tla` models `compile_mask_plan` validation, full sample
qualification and publication. `ModifierSerialState.tla` models its imported
raw header fold. Native capture models and Python contract tests cover the two
portable source envelopes. This component has no file, cache, process or Blender
resource lifetime. Its output is immutable input data, never rendered coverage.
The four guard mutants must fail; run the project-pinned tla-ts checker.

The bounded model checks one abstract track/sample; implementation bounds are
64 tracks, 10,000 inclusive ticks and 200,000 track samples. Tests cover dense
actual track iteration, exact serial/parent/hero/helper identity, missing owner
arrays and stable indefinite wire profile. Proto parsing/digests are validated
by imported contracts and tests, not established by the abstract model.

Native external-camera predicate: alive and owner property known, with word1
bits1/2 clear in both enabled and predicted arrays. Word3's local-camera gate
does not suppress an external Blender camera. Disabled words are retained but
not ORed into the predicate. Owner presence is a separate input. The planner
does not infer a body attachment, particle birth, seed, age or render lifetime.

Live evidence for the retained clip is decisive against immediate gate-hiding:
Mina's life state is2 and her model still exists at18191; her mask root is absent
at18193/18200/18240. Venator's model remains at all five endpoint observations.
The two-tick bracket is not a generic delay rule or exact subframe schedule.
Until a separate lifetime backend is qualified, this plan must not be dispatched
through the sampled-particle renderer or counted as a supported effect root.

Design simplification: existing serial folding is reused, rather than creating
another modifier ledger. Static sustained profiles are qualified once, then
owner snapshots are joined by exact identity and tick. No second activation
machine, default owner fields, synthetic CREATE or seed/phase state is added.
Initial model drafts exposed an assignment-precedence mistake (`q'=a /\ b`
constrained b rather than assigning a conjunction). Corrected to parentheses;
all input combinations and four guard mutants now execute. Drafts/logs retained
privately; final bounded model has11 states/depth5, four mutants killed.
