The additive normal projectile stage uses the existing whole-instance Blender
transaction. ProjectileEffectAdmission composes its input/source/asset checks,
fresh diagnostics directory, synchronous child process, bound response and positive
render outcome. Native input publication is modeled by native/src/ProjectileCapture.
ParticleModelAdmission covers late renderer rollback, including shape-key IDs.
The report merge is a synchronous addition of counts/lists; it owns no retry,
queue, persistent cache, concurrent writer or separate cleanup lifecycle.

Package admission revalidates capture envelope and selected track/owner, literal
Source coordinate basis, request digest, seed, inclusive timing, exact instance
and required CP/lifecycle fields. Existing non-projectile scene identities remain
unchanged. The new projectile backend explicitly binds full capture provenance
and track digests. Cropped views retain the original unmodified sidecar envelope.

The checked bounds are one independent instance and Boolean qualification/results;
concrete tests establish typed fields, exact hashes and numeric conversions.
Actual normal CLI export and saved/reopened Cycles checks establish integrated
behavior on the declared replay, not all game particles or Source visual parity.

Morph curve encoding is a synchronous pure transformation, with no new lifecycle.
Blender stores frame and weight values in float32. The encoder checks the union
of original and encoded knots, bounding the complete piecewise-linear curve to
1e-5 absolute weight error before consolidating coincident encoded times. A larger
change still refuses. Numeric and actual bpy/save/reopen tests cover this rule;
it is not a native animation-clock or exact Source shader equivalence claim.
Bundle discovery/settings reconciliation are likewise synchronous pure path/dict
transformations; they start no process and add no cache/lock/retry state.
