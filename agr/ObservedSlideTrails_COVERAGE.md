# Measured current-property slide trails

`observed_slide_trail_states` admits only the pinned slide_streaks definition,
static beam texture, renderer-input profile and registered native layout. The
optional stage consumes an explicit reference; ordinary replay extraction and
CRAV interfaces are unchanged. Native projection/upload files are bounded to
8 MiB each, paired by file digest and tied to the SAME audited sprite capture's
report, replay, scene, inclusive range, native modules and dense current roots.
The embedded sprite proof retains cleanup/source provenance. Portable hashes
detect changes, not maliciously forged claims. No executable is loaded from a
reference. Layout/gather/upload/helper proofs remain independently qualified;
none is an actual native GPU frame or complete Source appearance proof.

`ObservedSlideTrailFrames` models immutable input admission and ordered complete
frame publication: two ticks, two frame-local root slots, absent/empty/positive/
missing, replay identity and renderer qualification. Default: 2291 states, depth5;
all five identity/renderer/missing/previous-root/prefix mutants fail their named
rules. Terminal return states allow deadlock checking. This is finite component
coverage composed with existing `ModifierMaskRender` validation/allocation/whole
new-datablock rollback; it is not whole-application or unbounded liveness proof.

`blender_observed_slide_trails` samples the evaluated camera and precomputes all
whole-frame geometry before allocating meshes. No particle/root ID is joined
across ticks; current absent roots never prove no orphan effects. Each mesh
holds for one native tick interval, including the last captured array. The old
scene frame restores in `finally`; generic package ownership handles exceptions.
Only actual uploaded XYZW controls, packed tail/head colors and crop/flip bytes
feed the stateless shader math. Disabled fades/clamping/bias and literal texture
scales are admitted by the exact measured input pin; no guessed defaults. The
material is explicitly neutral-light partial reconstruction. Native texture
pixel hash is checked when packed. Unknown profiles and animated sheets refuse.

`build_captured_frame` is stateless numeric expansion. The build-local geometry
list, material and objects are owned by one synchronous package call; there are
no persistent caches, handlers, inferred births, clocks or publication state.
The optional effect stage uses exclusive package creation and existing rollback.
Merging only adds objects/lights and component limitations/unsupported entries;
recorded birth counters and strict/partial coverage gates are not rewritten.
