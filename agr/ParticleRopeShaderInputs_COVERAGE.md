# Bounded rope shader and depth inputs

`particle_rope_shader_inputs` binds the current measured Windows particle module
and three installed spritecard shader digests. The packet requires the exact
zero segment seed and blend-parameter table. Old plain ropes without new inputs
retain their earlier behavior; a missing proof never supplies a new default.
Changed modules, shaders, policy fields, seeds and blend constants refuse.

Detached native checks execute the current complete segment gather/copy slices
for32 prepared cases and all8 scalar writer variants for256 prepared cases.
The typed rope draw vtable binds their current caller. Each executed slice has
the exact previously qualified bytes. Native segment seed0 produces zero UV
random offsets. Attribute39/40 is not invented when missing. New per-particle
rope distortion/scale selectors and clamped UVs remain refused in this adapter.

The typed blend enum/native table gives ALPHA=1, ADD=0, BLEND_ADD=-1. Twenty-one
prepared native selection cases pass. The installed shader's parameter equation
retains alpha while leaving BLEND_ADD RGB unattenuated. The Blender graph uses
emission plus color-weighted transparency, including alpha0 without division.
Its ONE/INV_SRC_ALPHA reference composition is an explicit approximation: no
game GPU fixed blend-state/framebuffer, scene lighting or filtering parity is
claimed. Asset-free actual Cycles build/reopen each pass18 independent analytic
pixels spanning three modes, three alpha values and two child ages.

Depth-biased meshes carry the original source position, projective weight,
weighted UV and weighted color/alpha. Materials divide interpolated values by
the weight. Conservative homogeneous X/Y/W trivial rejection removes only
triangles strictly outside an unchanged clip plane, with a float32 roundoff
envelope. It introduces no clipped vertices or attribute interpolation. All
remaining vertices retain strict camera-plane, near/far and source-floor gates.
Original input vertices still count toward the existing allocation bound.

Live cards use the same proof only when entire triangles are invisible and bias
is nonnegative. The live graph either keeps a behind-camera vertex unchanged or
multiplies front-camera homogeneous coordinates by a positive factor, preserving
each XY/W plane sign. Source vertices remain in the card; potentially visible
mixed-plane cards and negative-bias exceptions still require the original proxy
bounds. Camera edits require requalification, not a silent unsupported fallback.

These functions add immutable derived attributes and numeric transforms, not a
new cache, playback clock, persistent RNG, worker or owner. The existing package
transaction owns all Blender IDs; `ParticleModelAdmission.tla` composes source,
default, capture and whole-instance rollback. Its40 states/five guard mutants do
not prove native arithmetic, clipping or Blender internals. Pure math tests use
an independent polygon clipper; actual packed pixels and saved data are separate.
