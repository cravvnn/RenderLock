Port status: component API only; no ordinary CLI cohort input or fresh normal slide acceptance yet. Historical native pins and original fingerprints remain.

The evaluated-light reference is dense, immutable, scene/replay/native/hash bound,
with explicit whole current-root arrays per tick. Positive particles require
observed descriptors; a null or unavailable output refuses admission. Empty
roots remain separate from missing roots. No identity is joined across frames.
The raw input adapter inherits exact tick, read budget, ownership, restoration
and owned-archive checks. It does not convert read stability into submitted-frame
or GPU/common-clock proof. Digests detect changes, not malicious forgeries.

particle_point_light is per-call finite numeric decoding/conversion, with no
state across calls; no lifecycle model is needed. Only the measured omni,
quadratic flags/coefficient profile is supported. Native color, range, position,
shadow flag and falloff offset are retained; no intensity/default reconstruction.
The Blender unit/radiometry/BRDF adaptation remains explicitly partial.

The builder precomputes immutable per-frame inputs before allocation, then owns
only local new objects. It uses existing build_package_effects ownership over
objects/collections/lights/actions/node groups, including whole-call rollback.
No new handler, cache, tracker, timer or cleanup protocol. No duplicate rollback
owner is added. Existing ModifierMaskRender models that abstract transaction;
ObservedSlideTrailFrames models the reused dense whole-array frame publication
interface (absent/empty/positive/missing, identity, renderer qualification, no
previous-root reuse). Shader math and actual bpy allocation/rollback/visibility
must be checked empirically; the finite models do not prove those operations.

Simplification: retain complete frame-local light objects and existing package
