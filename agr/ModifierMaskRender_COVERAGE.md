# Modifier-derived model rendering

`ModifierMaskRender.tla` covers the new `build_package_effects` backend dispatch:
qualification before allocation, success reporting, and whole-new-datablock
rollback on render exceptions. The imported `ModifierMaskPlan.tla` covers input
qualification. The same package transaction still wraps sampled particles;
this does not claim a new proof of every old backend or the whole application.
The finite per-package model has 9 states and five guard mutants killed,
including separate input-identity and sustained-gate admission guards. No
observed-slide or measured-lifecycle backend is part of this integration.

`modifier_mask_model` validates synchronous immutable inputs. Its metadata helper
uses the existing `AssetConverter._entry` content-verified cache unchanged; the
existing cache protocol is not redesigned or newly certified here. Typed helper
files/settings, exact model sources, full child-definition fingerprint, actual
module/VData bytes, attachment influence/rotation and authored mesh bindings
remain independently checked. No fallback scale, attachment or mesh index.
The owner descriptor resolves the unique installed resource matching the exact
recorded handle and binds source bytes plus evaluated skeleton bytes/names.
This pure validation does not require or enable optional procedural bone rules.

`build_modifier_mask_effects` iterates tracks independently; a refusal is a named
coverage entry. Fresh package files use exclusive creation. Model branch counts
are separate from recorded-instance/birth counts. Unknown parent-root layers
remain unsupported. The caller's camera is already constructed before effects.

`blender_modifier_masks` samples evaluated posed bones, creates only new model
objects/actions and restores prior frame/rig ancestry visibility in `finally`.
An outer package exception removes new objects/collections/meshes/materials/
images/actions and other supported datablocks. Numerical and saved-scene tests
must establish actual Blender behavior; passing this model alone does not.

The only admissible profile is sustained positive native gate and available
owner at every output tick. Measured model/lifecycle references are explicitly
refused before allocation. Native stop requests never become instant hiding or
a hardcoded delay. Missing/changed/partial samples refuse before geometry.
Sampled pose interpolation does not certify native render-subframe/pixel visibility.
No birth, seed or age is synthesized. Current hero pose is used without a guessed
interpolation offset. Parent ambient layers, lighting/shader parity and exact native
render-clock equivalence remain separately incomplete requirements.

Simplification: reuse the raw serial plan, shared authored six-mesh/material
importer and existing package rollback instead of introducing another particle
simulator, modifier ledger or resource cleanup owner. The new renderer holds no
cross-call cache, frame handlers or runtime process resources.
